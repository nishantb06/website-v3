# Obsidian

Obsidian is a local-first markdown note-taking app built around **linking**. Notes reference each other with `[[wiki-links]]`, and the graph view visualizes the resulting network — which is exactly what this page recreates.

## Why linked notes work

- Ideas rarely fit a single hierarchy; links let a note belong to many contexts
- Backlinks surface unexpected connections
- The graph view reveals clusters of related thinking

## This page

The graph you are looking at is built the same way: markdown files in a folder, edges parsed from wiki-links, rendered as a force-directed graph in [[nextjs]].

Good starting points: [[machine-learning]] and [[docker]].
